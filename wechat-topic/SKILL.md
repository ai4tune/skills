# 公众号选题技能

根据用户的一句话目标、品类选择或热点推荐，生成结构化的选题方案和内容方案 Brief。每个选题包含切入角度、内容大纲、多组标题备选和风险点标注。优化方向为可落地、有传播力、规避合规风险。

Read [references/topic-template.md](references/topic-template.md) 获取选题卡片的标准输出格式。
Read [references/category-matrix.md](references/category-matrix.md) 获取公众号内容品类矩阵和视觉系统。
Read [references/hot-topic-sources.md](references/hot-topic-sources.md) 获取热点信息源配置。
Read [references/style-memory.md](references/style-memory.md) 获取用户选题偏好记忆，用于优化推荐。

## 热点监控模式

本技能支持定时热点抓取与智能选题推荐，让你每天醒来就有现成选题可选。

### 工作原理

```
定时任务（如每天 7:00）
    │
    ▼
抓取各平台热点 → 按账号定位筛选 → 生成选题推荐 → 推送给用户
```

### 配置参数

| 参数 | 说明 | 示例 |
|------|------|------|
| 信息源 | 要抓取的平台列表 | 36 氪、TechCrunch、微博热搜、知乎热榜 |
| 抓取频率 | CronJob 执行频率 | 每天 7:00 / 每 6 小时 / 手动触发 |
| 账号定位 | 你的公众号领域关键词 | AI 工具、餐饮创业、职场成长 |
| 推荐数量 | 每次推送几个选题 | 3-5 个（默认 3） |
| 过滤规则 | 排除不相关话题 | 排除娱乐八卦、体育赛事 |

### 热点筛选逻辑（双层过滤）

抓取到的热点经过双层过滤（借鉴 AutoContents 模式）：

**第一层：关键词过滤**
- **正向关键词**：只保留命中列表中任意关键词的话题（留空则全部通过）
- **屏蔽关键词**：包含屏蔽词的话题直接丢弃
- 作用域可配置：仅标题 / 标题+摘要

**第二层：智能评估**

1. **相关性过滤**：只保留与账号定位匹配度 ≥ 60% 的话题
2. **时效性评估**：标注热点的"窗口期"（🔥 立即蹭 / ⏰ 24h 内 / 📅 一周内可写）
3. **风险预筛**：自动排除高敏感话题，标注中等风险话题

### 热点推送格式

```
🔔 今日热点选题推荐（2024-06-15 07:00）

基于你的账号定位「AI 工具评测」，筛选出以下热点：

1. 🔥 [立即] Claude 发布新模型 → 可切入：工具评测 + 热点解读
2. ⏰ [24h] OpenAI 调整定价策略 → 可切入：商业分析
3. 📅 [本周] AI 编程工具市场报告发布 → 可切入：行业干货 + 数据支撑

回复编号进入选题详情，或回复「更多」查看完整热点列表。
```

### 两种使用方式

| 方式 | 说明 | 适用场景 |
|------|------|----------|
| **被动推荐** | 定时自动推送热点选题 | 日更创作者，每天早上看推荐 |
| **主动触发** | 用户说"帮我看看今天有什么热点" | 灵活创作者，按需查看 |

## 内容品类矩阵

本技能内置 12 种公众号主流内容品类，详见 [references/category-matrix.md](references/category-matrix.md)。

用户可以：
1. **从品类中选择**：直接告诉 AI 想做哪个品类（如"行业干货"）
2. **品类叠加**：组合两个品类制造差异化（如"商业分析 + 情感共鸣"）
3. **一句话描述**：AI 自动匹配最合适的品类

### 品类叠加规则

- 最多叠加 2 个品类
- 叠加时以第一个品类为主调，第二个品类为辅调
- AI 会评估叠加组合的可行性和差异化潜力
- **视觉系统**：主调品类决定主色和封面风格，辅调品类的 Emoji 可用在正文小标题中

**叠加示例**：
| 组合 | 效果 | 适用场景 |
|------|------|----------|
| 行业干货 + 热点解读 | 借热点讲行业深度 | 某行业出了大新闻时 |
| 个人成长 + 商业分析 | 从商业视角讲个人发展 | 职场人群定位号 |
| 科技科普 + 生活方式 | 科技如何改变生活 | 泛科技号 |
| 情感共鸣 + 行业干货 | 用故事包裹干货 | 垂直行业但想破圈 |

## 输入规范

用户提供一句话目标，AI 自动拆解以下维度：

| 维度 | 说明 | 示例 |
|------|------|------|
| 领域 | 内容所属行业或话题域 | 小龙虾餐饮、AI 工具、职场成长 |
| 受众 | 目标读者画像 | 25-35 岁上班族、餐饮创业者、技术开发者 |
| 风格 | 写作调性 | 干货型、故事型、争议型、情绪型、科普型 |
| 时长 | 文章预期字数范围 | 800-1500 字（短文）、2000-4000 字（长文） |
| 频率 | 更新节奏 | 日更、周更、不定期 |
| 品类 | 内容品类（可叠加） | 行业干货、热点解读、商业分析 + 情感共鸣 |

如果用户未提供某个维度，AI 应基于领域合理推断并声明推断理由。

## 工作流程

1. **品类匹配**
   如果用户未指定品类，AI 根据一句话目标自动匹配 1-2 个最合适的品类，并说明匹配理由。

2. **意图拆解**
   解析用户的一句话，提取领域、受众、风格、时长、频率、品类六个维度。对缺失维度做合理推断。

3. **选题矩阵生成**
   基于以下策略生成 3-10 个选题：
   - **热点挂钩**：关联当前时事热点或节气节日
   - **痛点回应**：针对受众核心痛点提供解决方案
   - **认知颠覆**：打破常见误区或提供反直觉观点
   - **故事驱动**：以真实案例或虚构场景引入
   - **数据支撑**：以数据、排名、对比为核心卖点
   - **知识科普**：深入浅出解释专业概念

4. **风险标注**
   对每个选题评估三类风险：
   - 🔴 **敏感风险**：涉及政治、宗教、民族、性别等敏感话题
   - 🟡 **夸大风险**：标题党倾向、数据可能失实、承诺过度
   - 🟠 **合规风险**：广告法违规（绝对化用语）、医疗/金融等行业限制

5. **排序推荐**
   按以下权重排序：传播潜力 40% + 落地难度 30% + 风险可控性 30%

6. **内容方案 Brief**（用户选定选题后生成）
   为用户选定的选题生成一份内容方案，包含：
   - **标题备选** × 3 + 卖点分析（为什么这个标题能吸引点击）
   - **文章节奏规划**：开头钩子 → 信息递进 → 高潮金句 → 行动指引
   - **段落大纲**：每段标注核心钩子类型（🔥 高潮段 / 💡 数据段 / 💬 金句段 / 🎯 行动段）
   - **阅读价值评估**：这篇值得写吗？预期传播力如何？
   - **配图建议**：封面图和正文配图方向

## 输出规范（第一阶段：选题卡片）

为每个选题生成一张选题卡片，格式参照 [references/topic-template.md](references/topic-template.md)。

每张卡片必须包含：
- **选题编号与标题**（推荐标题）
- **匹配品类**：标注该选题属于哪个品类（或品类组合）
- **切入角度**：一句话描述核心视角
- **内容大纲**：3-5 个段落要点
- **标题备选**：至少 3 个不同风格的标题
- **风险标签**：使用 🔴🟡🟠 标记
- **推荐指数**：⭐ 1-5 星

## 输出规范（第二阶段：内容方案 Brief）

用户选定选题后，输出结构化的内容方案：

```
## 📋 内容方案 Brief

### 选题：[选题标题]
### 匹配品类：[品类名称]

---

### 标题方案
| 标题 | 风格 | 卖点分析 |
|------|------|----------|
| [标题A] | 干货型 | [为什么能吸引点击] |
| [标题B] | 情绪型 | [为什么能吸引点击] |
| [标题C] | 悬念型 | [为什么能吸引点击] |

### 文章节奏规划
| 段落 | 类型 | 钩子 | 占比 |
|------|------|------|------|
| 开头 | 🎣 钩子段 | [具体钩子描述] | 10% |
| 第一节 | 💡 数据段 | [数据冲击点] | 20% |
| 第二节 | 🔥 高潮段 | [核心论述点] | 30% |
| 第三节 | 💬 金句段 | [可传播金句] | 25% |
| 结尾 | 🎯 行动段 | [行动引导] | 15% |

### 阅读价值评估
- 目标读者痛点匹配度：[高/中/低]
- 预期传播力：[⭐⭐⭐⭐⭐]
- 写作难度：[⭐⭐⭐]
- 时效性：[常青 / 1周 / 3天]
- 建议：[值得写 / 谨慎考虑 / 建议换题]

### 配图建议
- 封面图：[方向描述]
- 正文配图 ×[N]：[各配图方向]
```

## 输出规则

- 所有输出为纯 Markdown 文本，不包含代码块或 JSON
- 选题编号连续，从 1 开始
- 每个选题独立成卡片，卡片之间用分隔线隔开
- 如果用户提供了「已用选题清单」，生成时自动去重排除
- 风险标注必须具体说明风险点，不能只打标签
- 内容方案 Brief 在用户选定选题后才生成（不要一次性为所有选题生成）

## 质量要求

- 标题不超过 30 个汉字
- 大纲要点必须是可执行的写作指引，不是抽象概念
- 角度必须差异化，不能只是同一主题的换皮
- 至少有 1 个选题采用「争议/反直觉」角度
- 至少有 1 个选题适合作为「系列选题」的第一篇
- 内容方案 Brief 的节奏规划必须具体到每段的钩子描述

## 示例触发

以下提示词应触发本技能：

- "帮我想 5 个关于小龙虾餐饮的公众号选题"
- "我要做一个 AI 工具评测的自媒体，帮我出选题"
- "给职场新人写公众号，选题方向有哪些"
- "下周端午节，帮我策划节日相关的推文选题"
- "用「商业分析 + 情感共鸣」的组合帮我出选题"
