# 选题卡片模板

每个选题按以下结构输出。多个选题之间用 `---` 分隔。

## 选题 [编号]：[推荐标题]

**匹配品类**：[品类名称（或品类A + 品类B）]

**切入角度**：[一句话核心视角]

**推荐指数**：[⭐⭐⭐⭐⭐]

**内容大纲**：
1. 🎣 [开头段：具体的钩子描述]
2. 💡 [数据/论述段：具体描述]
3. 🔥 [高潮段：具体描述]
4. 💬 [金句/案例段（可选）]
5. 🎯 [行动段：引导读者行为]

**标题备选**：
- A：[干货型标题]
- B：[情绪型标题]
- C：[悬念型标题]

**风险评估**：
- 敏感风险：[🔴 高 / 🟢 低] — [具体说明]
- 夸大风险：[🟡 中 / 🟢 低] — [具体说明]
- 合规风险：[🟠 中 / 🟢 低] — [具体说明]

**适合版本**：[长文 / 短文 / 朋友圈 / 视频口播]

---

## 输出示例

### 选题 1：月薪 5000 的人，凭什么吃 200 块的小龙虾？

**匹配品类**：商业分析 + 情感共鸣

**切入角度**：从消费心理切入，探讨小龙虾为何能突破价格敏感区间

**推荐指数**：⭐⭐⭐⭐⭐

**内容大纲**：
1. 🎣 开头：以一个「点了 200 块小龙虾的白领」场景切入
2. 💡 数据段：小龙虾客单价 vs 人均收入数据对比
3. 🔥 高潮段：「社交货币」「仪式感消费」「情绪价值」三个消费心理深度分析
4. 💬 案例段：餐饮品牌如何利用这一心理定价
5. 🎯 行动段：一个反思性金句 + 引导留言讨论

**标题备选**：
- A：小龙虾经济学：为什么年轻人愿意花半天工资吃一顿？
- B：月薪 5000，却舍得吃 200 的小龙虾，图啥？
- C：200 块一斤的小龙虾，到底收割了谁？

**风险评估**：
- 敏感风险：🟢 低 — 消费话题无政治敏感性
- 夸大风险：🟡 中 — 注意价格数据需标注来源
- 合规风险：🟢 低 — 无广告法限制词

**适合版本**：长文 / 朋友圈
