## 学习规则

Agent 在以下时机更新此文件：

1. **选题完成后**：记录用户从 N 个选题中选了哪个，分析被选中 vs 被跳过的选题差异
2. **大纲修改后**：记录用户对大纲做了什么修改（增删段落、调整顺序、改钩子类型）
3. **文章修改后**：记录用户对成稿要求重写/修改的部分（哪些段落、什么方向）
4. **每 5 次选题后**：汇总分析，更新偏好规律和品类偏好

### 分析方法

```
1. 获取本次推荐的全部选题列表
2. 记录用户选择了哪个（编号、品类、风格）
3. 记录用户跳过了哪些
4. 对比两组的差异，提炼规律：
   - 偏好的品类组合
   - 偏好的标题风格（数据型/悬念型/争议型/情绪型）
   - 偏好的内容深度（深度长文 vs 轻量短文）
   - 回避的话题类型
5. 将规律追加到对应章节
```
