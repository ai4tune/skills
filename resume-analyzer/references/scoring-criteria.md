# 简历多维评分标准

## 评分维度

### 1. 专业能力（1-10 分）

评估候选人的技术栈深度和广度。

| 分段 | 标准 |
|------|------|
| 9-10 | 在核心领域有深度积累（5 年+），掌握前沿技术，有技术决策/架构设计经验 |
| 7-8  | 技术栈覆盖面广，有 2-3 个领域较深入，能独立解决复杂问题 |
| 5-6  | 具备岗位所需基础技能，但缺乏深度或前沿技术接触 |
| 3-4  | 技能与目标岗位有一定差距，需要较长培养周期 |
| 1-2  | 技能严重不匹配或几乎无相关经验 |

**关注信号**：
- ✅ 正面：提到具体技术方案选型理由、性能优化数据、开源贡献
- ⚠️ 负面：只列工具名不说深度、同一技术栈多年无进阶

### 2. 成就密度（1-10 分）

使用 **CAR 框架**（Challenge-Action-Result）评估量化成果。

| 分段 | 标准 |
|------|------|
| 9-10 | 多项可量化成就（收入增长 xx%、用户增长 xx 万、系统性能提升 xx 倍） |
| 7-8  | 有 2-3 个明确量化成果，体现个人贡献（而非团队笼统描述） |
| 5-6  | 有一些成果描述但缺乏量化，或量化数据不够具体 |
| 3-4  | 主要描述职责（"负责 xxx"），而非成果（"实现了 xxx"） |
| 1-2  | 几乎没有成果导向的描述，纯任务罗列 |

**关注信号**：
- ✅ 正面：使用"提升"、"优化"、"降低"、"增长"等结果动词 + 具体数字
- ⚠️ 负面：大量"负责"、"参与"、"协助"等模糊动词

### 3. 表达质量（1-10 分）

评估简历本身的写作质量和专业度。

| 分段 | 标准 |
|------|------|
| 9-10 | 结构清晰、措辞精准、层次分明、无冗余，每句话都有信息量 |
| 7-8  | 整体专业，结构合理，有少量可优化的地方 |
| 5-6  | 基本可读，但有明显的啰嗦、结构混乱或用词不当 |
| 3-4  | 表达混乱，逻辑跳跃，或过于简略缺乏细节 |
| 1-2  | 语法错误多、格式混乱、明显缺乏求职诚意 |

**关注信号**：
- ✅ 正面：STAR 格式叙述、清晰的时间线、针对性的技能描述
- ⚠️ 负面：大段复制粘贴、排版混乱、明显的模板痕迹未修改

### 4. 职业轨迹（1-10 分）

评估职业发展路径的连贯性和成长性。

| 分段 | 标准 |
|------|------|
| 9-10 | 清晰的上升曲线（职级/薪资/影响力递增），跳槽有明确成长逻辑 |
| 7-8  | 整体向上发展，偶有横向移动但有合理解释 |
| 5-6  | 发展轨迹平稳，无明显上升但也无明显问题 |
| 3-4  | 频繁跳槽（每份工作 < 1 年）、职级倒退、或有较长空窗期 |
| 1-2  | 职业路径混乱，无法看出发展方向 |

**关注信号**：
- ✅ 正面：稳定任期（2-4 年/份）、职级递增、行业深耕
- ⚠️ 负面：频繁跳槽、跨行业无逻辑、降级跳槽、大段空窗未解释

## 综合评级

| 总分 | 评级 | 建议 |
|------|------|------|
| 33-40 | ⭐⭐⭐⭐⭐ 优秀 | ✅ 强烈建议约见 |
| 25-32 | ⭐⭐⭐⭐ 良好 | ✅ 建议约见 |
| 17-24 | ⭐⭐⭐ 中等 | ⚡ 谨慎查看，视岗位紧急度决定 |
| 9-16  | ⭐⭐ 偏弱 | ❌ 不建议，除非有特殊考量 |
| 4-8   | ⭐ 不匹配 | ❌ 淘汰 |
