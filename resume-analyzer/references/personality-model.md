# 大五人格（OCEAN）分析框架

## 概述

大五人格模型是心理学界公认的、在预测工作绩效方面最具统计学效力的人格评估框架。通过分析简历中的语言特征，可以推断候选人的人格倾向。

> ⚠️ **重要声明**：基于简历文本的人格推断仅为参考性分析，不构成专业心理评估。实际人格需通过标准化测试工具确认。

## 五个维度

### 1. 开放性 (Openness)

**定义**：对新经验、创意和抽象思维的接受程度。

| 倾向 | 简历中的语言信号 |
|------|----------------|
| **高** | 词汇量丰富、使用抽象概念、描述跨领域迁移经验、提及创新项目、实验性工作、学习新技术的热情 |
| **中** | 有一定的技术探索但主要在本领域内、提及持续学习但范围有限 |
| **低** | 专注于单一技术栈、描述偏流程化、少见创新或实验性表述 |

**职场预测**：创新能力、对新技术/流程的适应性、学习敏捷性

### 2. 尽责性 (Conscientiousness)

**定义**：计划性、责任心和目标导向。

| 倾向 | 简历中的语言信号 |
|------|----------------|
| **高** | 逻辑结构严密、强调可量化结果、无语法/拼写错误、使用精确数字、清晰的目标导向叙述 |
| **中** | 结构基本清晰，有部分量化数据，偶有小瑕疵 |
| **低** | 格式不统一、描述含糊、缺少具体数字支撑、逻辑跳跃 |

**职场预测**：责任感、执行力、对细节的关注、长期绩效最强预测因子

### 3. 外向性 (Extraversion)

**定义**：社交能量和人际互动的积极程度。

| 倾向 | 简历中的语言信号 |
|------|----------------|
| **高** | 频繁使用动感动词、强调团队合作和跨部门协调、描述演讲/培训/客户沟通、使用影响力导向语言 |
| **中** | 提及团队协作但非重点突出、有一些对外沟通描述 |
| **低** | 侧重独立工作描述、技术深耕为主、少提人际互动场景 |

**职场预测**：团队协作能量、沟通积极性、客户关系维护能力

### 4. 宜人性 (Agreeableness)

**定义**：合作性、利他倾向和同理心。

| 倾向 | 简历中的语言信号 |
|------|----------------|
| **高** | 强调社区贡献/开源参与、指导/培训他人、使用包容性语言（"我们"而非"我"）、提及团队建设 |
| **中** | 有一定的协作描述，但更多关注个人成就 |
| **低** | 强调个人竞争成果、语言偏强势/独断、少见团队贡献描述 |

**职场预测**：冲突解决能力、团队凝聚力、跨文化适应性

### 5. 情绪稳定性 (Emotional Stability)

**定义**：面对压力和不确定性时的冷静程度。

| 倾向 | 简历中的语言信号 |
|------|----------------|
| **高** | 表达自信、语气客观冷静、描述压力场景时聚焦解决方案、面对挑战的叙述理性有序 |
| **中** | 整体平稳，无明显情绪化表达 |
| **低** | 过度使用感叹号/强调、频繁自我辩解、对负面经历过度着墨 |

**职场预测**：抗压韧性、在高压环境下的决策稳定性

## 分析规则

1. **必须引用原文**：每个维度的判断必须引用简历中的原始短语作为证据
2. **避免过度推断**：如果某个维度在简历中缺乏可分析的信号，标记为"信号不足，无法判断"
3. **注意文化差异**：中文简历的表达习惯与英文简历不同，不应以英文标准直接套用
4. **考虑简历风格**：技术岗简历天然偏内敛，不应因此给外向性打低分
