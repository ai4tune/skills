# 公众号文章创作技能

一站式完成公众号文章的选题、大纲、写作和质量自检。输出标准 Markdown 格式。

Read [references/style-guide.md](references/style-guide.md) 获取写作风格规范。
Read [references/self-check.md](references/self-check.md) 获取五维度质量自检标准。

## 工作流程

### 第 1 步：选题（⛔️ 必须暂停等用户选择）

根据用户的一句话目标，生成 3 个选题方案：

```
📝 为你生成了 3 个选题：

1. ⭐⭐⭐⭐⭐ 标题（推荐理由）
2. ⭐⭐⭐⭐ 标题（推荐理由）
3. ⭐⭐⭐⭐ 标题（推荐理由）

回复编号选择，或说「重新生成」。
```

⛔️ **此处必须停下来等用户选择。绝不自动选题。**

### 第 2 步：大纲确认（⛔️ 必须暂停等用户确认）

展示文章骨架：

```
📋 文章大纲：《标题》

开头：场景/悬念/数据钩子
第一节：小标题 → 核心内容
第二节：小标题 → 深入展开
第三节：小标题 → 高潮/洞察
结尾：金句收束 + 互动引导

预计 2000 字
```

⛔️ **此处必须停下来等用户确认。绝不跳过。**

### 第 3 步：写作

用户确认大纲后，开始写作。输出**标准 Markdown**：

**写作要求：**
- 故事体，不是报告体（开头用场景，不用"本文将介绍"）
- 开头 3 行必须是钩子：场景画面 / 悬念 / 数据冲击
- 每个观点必须有具体案例或数据
- 短段落（1-3 句话），多用换行
- 每 2-3 段插入一个引用块或列表，打破阅读节奏
- 结尾用金句收束 + 一个互动问题

**Markdown 格式规范：**
- 用 `##` 作为章节标题
- 用 `**加粗**` 强调关键词
- 用 `>` 引用块做强调（观点/重点/提示）
- 用 `-` 或 `1.` 做列表
- 配图位置用 `![描述](image)` 标记

**配图规则：**
- 封面图：标题下方
- 正文插图：第 2 节和第 4 节后各一张
- 绝不在文章最后一段后放图
- 配图标记格式：`![AI配图：描述 | 风格 | 色调](generate)`

### 第 4 步：自检（⛔️ 必须暂停展示结果）

写完后自动进行五维度自检（详见 [references/self-check.md](references/self-check.md)）：

```
✅ 文案完成 | 《标题》2136字

📊 自检结果：
· 信息密度：8/10
· 标题吸引力：9/10
· 金句质量：7/10
· 排版友好度：8/10
· 合规安全：9/10
· 总分：41/50 ✅

💡 排版提示：运行 wechat-format 技能将 Markdown 转为公众号格式
```

⛔️ **此处必须停下来。** 等用户确认或提出修改意见。

## 输出要求

- 输出纯 Markdown，不加任何 HTML/CSS
- 不输出 `金句：` `引导关注：` `摘要：` 等标签前缀
- 金句和强调自然融入正文
- 全文 1500-2500 字

## 示例触发

- "帮我写一篇关于 AI 工具的公众号文章"
- "写一篇 OpenClaw 变现的推文"
- "帮我出一篇端午节的公众号文章"
