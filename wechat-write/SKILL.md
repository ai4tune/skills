# 公众号文案生成技能

将选题和素材卡片转化为结构完整、风格统一的公众号文章。输出可直接粘贴到公众号编辑器的 Markdown/富文本内容。每篇文章自动附带五维度质量自检报告。

Read [references/article-template.md](references/article-template.md) 获取文章结构模板。
Read [references/style-guide.md](references/style-guide.md) 获取写作风格参数和排版规范。
Read [references/self-check.md](references/self-check.md) 获取五维度质量自检标准。
Read [references/output-schema.md](references/output-schema.md) 获取结构化输出 Schema（段落类型、校验规则、下游消费方式）。

## 输入规范

| 参数 | 必填 | 说明 |
|------|------|------|
| 选题 | ✅ | 来自 wechat-topic 的选题卡片（含角度、大纲）或内容方案 Brief |
| 素材卡片 | ✅ | 来自 wechat-research 的素材列表 |
| 风格模版 | ❌ | 口吻/结构/长度偏好（默认使用 style-guide） |
| 输出版本 | ❌ | long/short/moments/video（默认 long） |
| 目标字数 | ❌ | 期望字数范围（默认 1500-3000 字） |

## 版本类型

| 版本 | 字数范围 | 特点 |
|------|----------|------|
| **long** 长文 | 1500-4000 字 | 完整结构、深度分析、适合公众号推文 |
| **short** 短文 | 500-1000 字 | 精炼要点、快速阅读、适合次条或栏目 |
| **moments** 朋友圈 | 50-200 字 | 核心金句 + 引导语、适合朋友圈/社群转发 |
| **video** 视频口播 | 300-800 字 | 口语化、有节奏感、适合短视频/直播口播稿 |

## 工作流程

1. **大纲锁定**
   基于选题的内容方案 Brief（如有）或大纲，确认文章骨架：
   - 验证每个段落都有明确的钩子标记（🎣🔥💡💬🎯）
   - 确认素材能覆盖所有关键段落
   - **大纲未确认前不进入正文写作**

2. **结构规划**
   基于锁定的大纲，确定文章骨架：
   - 开头策略（故事引入 / 数据冲击 / 提问互动 / 场景描写）
   - 正文节奏（论点-论据-案例 交替推进）
   - 结尾策略（金句收束 / 行动号召 / 开放讨论 / 悬念预告）

3. **素材编排**
   将素材卡片匹配到文章各段落：
   - 每个论点至少 1 条素材支撑
   - 数据和引用自然融入行文，不堆砌
   - 标注素材来源（文中注明或文末统一标注）

4. **风格适配**
   根据 [references/style-guide.md](references/style-guide.md) 调整：
   - 人称与口吻（你/我/我们）
   - 句式节奏（长短交替、段落长度）
   - 情绪曲线（开头抓人 → 中间递进 → 高潮金句 → 结尾余韵）

5. **正文写作**（严格执行 [references/style-guide.md](references/style-guide.md) 的反面教材规则）
   严格按照锁定的大纲逐段展开：
   - **禁止报告体**：不允许通篇 "首先...其次..." 的结构，必须用场景/故事/对话感
   - **3 行钩子规则**：开头 3 行内必须出现场景画面或悬念
   - **交替节奏**：每 3 个要点穿插 1 个故事/场景/对话
   - **视觉切换**：每 300-500 字必须有一个排版切换点（引用块/加粗句/配图/分隔线）
   - **每个概念必举例**：不允许空讲概念，必须跟一个 "比如说..."
   - **情绪节奏**：每 500 字至少有 1 个情绪触发点（惊讶/共鸣/好笑/愤怒）

6. **AI 配图生成**
   文章写完后，在关键位置插入 AI 配图标记，并调用图片生成 API：
   - **封面图**：1 张，21:9 比例，呼应标题主题
   - **正文插图**：每 500-800 字插入 1 张，呼应当前段落
   - **金句图**：为核心金句生成配图（可选）
   - 配图标记格式：`[📷 AI配图 | 风格：[风格] | 内容：[描述] | 色调：[色调]]`
   - 图片风格根据文章品类自动匹配（参照 style-guide.md 配图风格指引）
   - **长文至少 3 张配图**（含封面），**短文至少 1 张封面**

7. **排版美化**（严格参照 [references/style-guide.md](references/style-guide.md) 排版规范）
   公众号原生排版，**严禁 HTML/CSS/div/style**：
   - **每段不超过 3 行**，重要句子单独一行
   - **每 3 段插入一个强调块**（`🔥 观点` / `⚠️ 重点` / `📌 提示` + 引用块）
   - 章节标题用 `——— 🧭 小标题 ———` 格式
   - 结构化信息用 **信息卡片**（`📌 场景名` + 列表）
   - 核心观点和数据 **加粗**
   - 引用/金句用 `>` 引用块
   - 多使用列表拆分密集信息

8. **五维度自检**（参照 [references/self-check.md](references/self-check.md)）
   文章完成后自动从 5 个维度检查，详见下方说明。

9. **多版本生成**（如指定）
   基于长文版本精炼出其他版本，保持核心观点一致。

## 五维度质量自检

文章写完后，AI 自动从以下 5 个维度进行质量评估，参照 [references/self-check.md](references/self-check.md)。

每个维度打 1-10 分，总分 50 分。低于 7 分的维度必须给出**具体修改意见**（不能只说"建议优化"）。

| 维度 | 核心问题 | 评分标准概要 |
|------|----------|-------------|
| 📊 **信息密度** | 干货够不够？ | 每 300 字至少 1 个独特信息点 |
| 🎯 **标题吸引力** | 会点开吗？ | 情绪触发 + 信息缺口 + 可信度 |
| 💡 **金句质量** | 会转发吗？ | 独立可传播、引发共鸣 |
| 📱 **排版友好度** | 手机读舒服吗？ | 段落≤5行、有小标题分割、有视觉节奏 |
| ⚖️ **合规安全** | 能过审吗？ | 无禁用词、无虚假信息、来源有标注 |

### 自检输出格式

```
## 📋 质量自检报告

| 维度 | 得分 | 状态 | 说明 |
|------|------|------|------|
| 📊 信息密度 | 8/10 | ✅ | 共 7 个独特信息点，密度达标 |
| 🎯 标题吸引力 | 9/10 | ✅ | 数据+悬念双钩子 |
| 💡 金句质量 | 6/10 | ⚠️ | 第二句金句太长，建议压缩到 20 字内 |
| 📱 排版友好度 | 8/10 | ✅ | 段落长度合理，小标题节奏好 |
| ⚖️ 合规安全 | 9/10 | ✅ | 无违规词，来源齐全 |

**总分**：40/50

### ⚠️ 需改进项
1. **💡 金句质量**（6/10）：
   - 问题：第二个金句「在这个时代...才是真正的赢家」过于空泛
   - 建议：改为具体场景化表达，例如「月薪 5000 的人吃 200 块的小龙虾，不是消费升级，是情绪刚需」
   - 修改位置：正文第三节结尾

### ✅ 亮点
- 开头用场景描写直接入画，3 行内抓住注意力
- 数据使用扎实，均标注来源年份
```

**自检判定规则**：
- 总分 ≥ 40：✅ 质量达标，可进入发布流程
- 总分 35-39：⚠️ 建议修改后发布
- 总分 < 35：❌ 质量不达标，需要重写或大幅修改

## 输出规范

文章按以下结构输出，格式参照 [references/article-template.md](references/article-template.md)：

```
# [文章标题]

> [文章摘要：1-2 句话，用于公众号摘要栏]

---

[正文内容]

---

**金句摘录**：
- [适合制作金句图的句子 1]
- [适合制作金句图的句子 2]

**引导关注**：
[引导读者关注的文案]

**参考来源**：
- [来源 1]
- [来源 2]

---

[📋 质量自检报告]
```

## 输出规则

- Markdown 格式，兼容公众号编辑器（支持标题、加粗、引用块、列表）
- 段落之间留一行空行
- 每段不超过 5 行（移动端阅读优化）
- 关键数据和核心观点用 **加粗** 标记
- 引用他人原文用 `>` 引用块格式
- 图片位置用 `[📷 配图建议：描述]` 占位标注
- 不使用 HTML 标签和复杂格式
- **每篇文章末尾必须附带质量自检报告**

## 质量要求

### 基本规则
- 标题不超过 30 个汉字，需包含至少 1 个情绪触发词或数据
- 摘要不超过 60 个汉字，需引发好奇心
- 开头 3 行内必须抓住读者（不允许平铺直叙的背景介绍）
- 正文至少包含 2 个小标题（`##`）分段
- 全文至少 2 处可独立传播的金句
- 结尾必须包含一个明确的行动指引（关注、留言、转发、收藏之一）
- 引用数据必须标注来源和年份
- 自检总分必须 ≥ 35 才能进入发布流程

### 写作质量红线
- ❌ **禁止报告体**：不允许 "一、二、三" 或 "首先、其次、最后" 作为全文骨架
- ❌ **禁止连续列表**：不允许连续罗列超过 5 条 list 没有叙述穿插
- ❌ **禁止空概念**：每个概念/论点必须跟一个具体例子或场景
- ❌ **禁止文字墙**：任何段落不得超过 5 行
- ❌ **禁止无配图**：长文必须至少 3 张 AI 配图（含封面）

### 排版质量红线
- ✅ 每段不超过 3 行，重要句子单独一行
- ✅ 每 3 段必须有一个强调块（🔥/⚠️/📌）
- ✅ 章节标题用 `——— 🧭 ———` 格式
- ✅ 核心数据和结论必须 **加粗**
- ✅ 引用和金句必须用 `>` 引用块
- ❌ 严禁使用 HTML / CSS / style / div
