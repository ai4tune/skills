# 公众号文案生成技能

将选题和素材转化为**可直接粘贴到微信公众号编辑器**的纯文本文章。

Read [references/style-guide.md](references/style-guide.md) 获取写作风格和排版规范。
Read [references/self-check.md](references/self-check.md) 获取五维度质量自检标准。

## ⛔️ 输出格式硬性规则

> 微信公众号编辑器**不支持 Markdown**！以下语法全部禁止：

| 禁止 | 替代方案 |
|------|---------|
| `**加粗**` | 用「加粗」或直接写，不加任何标记 |
| `## 标题` | 用 `——— 🧭 标题 ———` |
| `> 引用` | 用 emoji 前缀 + 换行缩进 |
| `- 列表` | 用 `· ` 或 `① ② ③` |
| `[链接](url)` | 直接写文字 |
| HTML/CSS/div | 绝不使用 |

## 工作流程

1. **大纲锁定** — 基于选题确认文章骨架，⛔️ 大纲未确认前不写正文
2. **正文写作** — 故事体（禁止报告体），3 行钩子开头，每个概念必举例
3. **排版美化** — 按下方排版规范处理
4. **AI 配图** — 在指定位置插入配图
5. **五维度自检** — 打分 + 修改建议

## 排版规范（内联，必须遵守）

### 章节标题
```
———
🧭 小标题文字
———
```

### 段落规则
- 每段不超过 3 行
- 重要句子单独一行
- 段落之间空一行

### 强调块（每 3 段必须有 1 个）
```
🔥 观点
这里写核心观点，一句话点明立场。

⚠️ 重点
这里写关键结论，可独立传播的金句。

📌 提示
这里写行动指引或补充说明。
```

### 信息卡片（结构化信息用）
```
📌 场景名称
· 要点一
· 要点二
· 要点三
```

### 加粗替代
用「」包裹关键词：`你卖的不是文字，你卖的是「确定性」`

## AI 配图规则

配图位置**写死**，不要自由发挥：

| 位置 | 说明 | 图片类型 |
|------|------|---------|
| 标题下方，正文开始前 | 封面图 | 21:9，呼应标题 |
| 第 2 个章节结束后 | 正文插图 | 呼应当前内容 |
| 第 4 个章节结束后（如有） | 正文插图 | 呼应当前内容 |
| ⛔️ 绝不放在文章最后一段后 | — | — |

配图标记格式：
```
[📷 AI配图 | 风格：扁平插画 | 内容：描述 | 色调：暖橙]
```

长文至少 3 张配图（含封面），短文至少 1 张封面。

## 五维度自检

文章完成后从 5 个维度打分（每项 1-10 分，总分 50）：

| 维度 | 核心问题 |
|------|---------|
| 信息密度 | 删掉任意一段，文章是否缺失信息？ |
| 标题吸引力 | 在信息流里，你会点开吗？ |
| 金句质量 | 有没有能截图转发的句子？ |
| 排版友好度 | 手机上滑动阅读舒服吗？ |
| 合规安全 | 有没有敏感/争议/夸大内容？ |

总分 < 35 → 自动重写低分段落。详细标准见 [references/self-check.md](references/self-check.md)。

### 排版自检清单
- ✅ 没有任何 Markdown 语法（`**`、`##`、`>`、`-`、`[]()` 等）
- ✅ 每段 ≤ 3 行
- ✅ 每 3 段有一个强调块（🔥/⚠️/📌）
- ✅ 章节标题用 `——— 🧭 ———`
- ✅ 配图在第 2、第 4 章节后，不在末尾
- ✅ 关键词用「」而不是 `**`

## 禁止出现的内容

以下文字不应出现在最终输出中：
- ❌ `金句：` `引导关注：` `摘要：` 等标签前缀
- ❌ `**加粗**` 等 Markdown 符号
- ❌ `[📷 AI配图]` 标记（配图生成后应替换为实际图片，或删除标记）
- ❌ HTML 标签
