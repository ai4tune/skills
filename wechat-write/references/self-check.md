# 五维度质量自检标准

文章完成后，从以下 5 个维度进行自动质量评估。每个维度 1-10 分，总分 50 分。

## 评分维度

### 1. 📊 信息密度（干货够不够？）

| 分数 | 标准 |
|------|------|
| 9-10 | 每 200 字有 1 个独特信息点（数据/案例/方法/观点），全文无水段 |
| 7-8 | 每 300 字有 1 个独特信息点，偶有过渡性段落 |
| 5-6 | 信息点分布不均，有 1-2 个明显水段 |
| 3-4 | 大量重复论述，信息量不足以支撑篇幅 |
| 1-2 | 通篇空洞，缺乏实质内容 |

**检查要点**：
- [ ] 删除所有「正确的废话」（如：众所周知、不言而喻、毋庸置疑）
- [ ] 每个论点都有数据或案例支撑
- [ ] 不同段落的信息点不重复
- [ ] 文章长度与信息量匹配（不为凑字数注水）

### 2. 🎯 标题吸引力（会点开吗？）

| 分数 | 标准 |
|------|------|
| 9-10 | 同时具备：情绪触发 + 信息缺口 + 读者相关性，让人「不得不点」 |
| 7-8 | 具备 2/3 要素，有明确吸引力 |
| 5-6 | 中规中矩，缺乏让人立刻点开的冲动 |
| 3-4 | 平淡无奇，或过于标题党失去可信度 |
| 1-2 | 令人困惑，或与内容严重不符 |

**检查要点**：
- [ ] 标题 ≤ 30 字
- [ ] 包含至少 1 个情绪触发词或数据
- [ ] 标题与正文内容一致（不是标题党）
- [ ] 在信息流中能从 10 条标题里脱颖而出
- [ ] 不使用被滥用的套路（震惊！/重磅！）

### 3. 💡 金句质量（会转发吗？）

| 分数 | 标准 |
|------|------|
| 9-10 | 2+ 句可独立传播，脱离文章上下文仍然有力量 |
| 7-8 | 2 句有传播力，但独立性稍弱 |
| 5-6 | 有金句意识但表达不够精炼 |
| 3-4 | 金句太长、太空、太鸡汤 |
| 1-2 | 无可传播的句子 |

**检查要点**：
- [ ] 每句金句 ≤ 25 字（越短越有力）
- [ ] 金句能脱离上下文独立理解
- [ ] 不是名人名言的复制（要有原创表达）
- [ ] 包含具体意象或数据（不是空泛的「大道理」）
- [ ] 放在文章 1/3 处和结尾各一句

### 4. 📱 排版友好度（手机读舒服吗？）

| 分数 | 标准 |
|------|------|
| 9-10 | 视觉清爽、节奏明快，拇指滑动无卡顿感 |
| 7-8 | 基本舒适，个别段落略长 |
| 5-6 | 有大段落堆积，缺少视觉切换元素 |
| 3-4 | 整体密集，缺乏层次 |
| 1-2 | 满屏文字墙 |

**检查要点**：
- [ ] 每段 ≤ 5 行
- [ ] 每 3-4 段有分隔元素（小标题/引用块/列表/配图位）
- [ ] 关键信息已加粗标记
- [ ] 有合理的留白（段间空行）
- [ ] 配图位置已标注（每 500 字建议 1 张）

### 5. ⚖️ 合规安全（能过审吗？）

| 分数 | 标准 |
|------|------|
| 9-10 | 零风险项，所有数据有来源，无敏感表述 |
| 7-8 | 无硬伤，个别表述可优化 |
| 5-6 | 有 1-2 处需修改的合规风险 |
| 3-4 | 存在明确的违规表述或未核实数据 |
| 1-2 | 多处违规，不可发布 |

**检查要点**：
- [ ] 无广告法绝对化用语（最、第一、唯一等）
- [ ] 无虚假数据或未标注来源的数据
- [ ] 无涉及政治、宗教、民族的敏感表述
- [ ] 无版权问题（引用已标注来源）
- [ ] 无歧视性语言
- [ ] 医疗/金融等特殊领域已加免责声明

## 总分判定

| 总分 | 判定 | 行动 |
|------|------|------|
| 45-50 | 🌟 **优秀** | 可直接发布 |
| 40-44 | ✅ **达标** | 可进入发布流程 |
| 35-39 | ⚠️ **待改进** | 建议修改低分项后发布 |
| 30-34 | ❌ **不达标** | 需较大修改 |
| < 30 | 🚫 **需重写** | 建议重新构思或更换选题 |

## 修改意见要求

对于得分 < 7 的维度，修改意见必须：

1. **指出具体位置**：第几段、第几句、哪个小标题
2. **说明具体问题**：不是"需要优化"，而是"这句金句太长（38字），超出25字上限"
3. **给出修改示例**：提供一个改写后的版本供参考
4. **评估修改影响**：修改后预计该维度能提升到几分
