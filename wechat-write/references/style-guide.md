# 公众号写作风格指南

## ⛔️ 第一原则：微信不支持 Markdown

微信公众号编辑器**不会渲染任何 Markdown 语法**。所有 `**`、`##`、`>`、`-`、`[]()`
都会原封不动显示在读者面前。

### 禁止 vs 替代对照表

| ❌ 禁止 | ✅ 替代 | 示例 |
|---------|--------|------|
| `**加粗文字**` | 用「」包裹 | 你卖的是「确定性」 |
| `## 标题` | ——— 🧭 标题 ——— | ——— 🧭 六条变现路径 ——— |
| `> 引用` | emoji 前缀 + 换行 | 🔥 观点（换行）内容 |
| `- 列表项` | · 列表项 或 ① ② ③ | · 要点一 |
| `[文字](链接)` | 直接写文字 | 详见官网 |
| `---` 分割线 | ——— | ——— |
| HTML/CSS/div/style | 绝不使用 | — |

## 排版规范

### 章节标题格式

```
———
🧭 小标题文字
———
```

示例：
```
———
🧭 变现的核心：你卖的不是 AI，是交付物
———
```

### 强调块（每 3 段插 1 个）

三种类型，轮流使用：

```
🔥 观点
这里写核心观点，一句话点明全文立场。

⚠️ 重点
这里写关键结论，适合截图传播的金句。

📌 提示
这里写行动指引或补充说明。
```

**选择规则**：
- 🔥 观点 → 适合：观点输出、热点解读、情感共鸣类文章
- ⚠️ 重点 → 适合：行业干货、商业分析、科技科普类文章
- 📌 提示 → 适合：教程攻略、工具评测、盘点清单类文章

### 信息卡片（结构化信息用）

```
📌 卡片标题
· 要点一：简要说明
· 要点二：简要说明
· 要点三：简要说明
```

### 段落规则

- 每段不超过 3 行
- 重要句子单独一行
- 段落之间空一行
- 关键词用「」包裹，不用 **

### 加粗替代

❌ 错误：`**交付物**：你最终交给对方什么`
✅ 正确：`「交付物」：你最终交给对方什么`

## 写作风格

### 故事体 vs 报告体

❌ 报告体（禁止）：
```
一、概述
OpenClaw 是一个智能体平台。
经过研究，总结出 6 种变现模式：
1. 内容变现
2. ToB 接单
```

✅ 故事体（要求）：
```
凌晨 0:13，我盯着对话框发呆。

"OpenClaw 到底怎么变现？"这句话我打了三次又删了三次。

🔥 观点
二十分钟后，3200 字的报告交到我手上。不是废话堆砌，是能发给甲方的东西。

那一刻我意识到——

这不是聊天工具，这是「变现工具」。
```

### 风格要点

| 规则 | 说明 |
|------|------|
| 3 行钩子 | 开头 3 行必须出现场景画面或悬念 |
| 每个概念必举例 | 不允许空讲观点，必须跟"比如说…" |
| 交替节奏 | 每 3 个要点穿插 1 个故事/场景/对话 |
| 情绪触发 | 每 500 字至少 1 个情绪点（惊讶/共鸣/好笑） |
| 金句密度 | 至少 2 条可独立截图传播的金句 |

## AI 配图规范

### 位置规则（写死）

| 位置 | 图片类型 |
|------|---------|
| 标题下方，第 1 段前 | 封面图（21:9） |
| 第 2 个章节结束后 | 正文插图 |
| 第 4 个章节结束后（如有） | 正文插图 |
| ⛔️ 绝不放文章末尾 | — |

### 配图标记格式

```
[📷 AI配图 | 风格：扁平插画 | 内容：描述 | 色调：暖橙]
```

### 品类→配图风格映射

| 品类 | 封面风格 | Prompt 关键词 |
|------|---------|--------------|
| 行业干货 | 信息图 | infographic, data, minimalist |
| 热点解读 | 新闻头条 | breaking news, bold, urgent |
| 商业分析 | 数据图表 | business chart, corporate |
| 科技科普 | 未来感 | futuristic, abstract, neon |
| 工具评测 | 界面截图 | tool interface, flat design |
| 人物故事 | 人物插画 | storytelling, character |
| 教程攻略 | 流程图 | step by step, checklist |

## 禁止出现的内容

以下「标签」不应出现在最终输出中：
- ❌ `金句：`
- ❌ `引导关注：`
- ❌ `摘要：`（正文开头直接写摘要内容，不加标签）
- ❌ `[📷 AI配图]`（生成图片后替换为实际图片，或删除标记）
- ❌ 任何 Markdown 语法符号

---

## 质量检查清单

输出前必须逐项确认：

- [ ] 没有任何 `**`、`##`、`>`、`-`、`[]()`
- [ ] 每段 ≤ 3 行
- [ ] 每 3 段有强调块（🔥/⚠️/📌）
- [ ] 章节标题用 ——— 🧭 ———
- [ ] 配图在第 2/4 章节后，不在末尾
- [ ] 关键词用「」不用 **
- [ ] 没有 `金句：` `引导关注：` 等标签泄露
- [ ] 至少 2 条可截图传播的金句
- [ ] 长文 ≥ 3 张配图
