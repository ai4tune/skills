# 公众号文章模板

## 文章结构

```
标题
摘要
正文（含强调块 + 信息卡片 + 章节标题 + 配图）
小结
```

## 完整模板（故事体 + WeChat 原生排版）

> ⚠️ 严禁使用 HTML / CSS / style / div！只使用 Markdown 原生语法。

```markdown
# [标题——30字以内，含情绪词或数据]

> [摘要：60字以内，引发好奇心]

[📷 AI配图 | 风格：呼应品类 | 内容：呼应标题 | 色调：暖/冷]

[3行钩子开头——场景/悬念/数据冲击]

[让读者"看见"画面，不是"读到"概念]

[第一段结束——此时读者决定是否往下看]

🔥 观点
> [核心观点——一句话点明全文立场]

———
🧭 [小标题一：用悬念或好奇心]
———

[叙述段落：≤ 3 行，用"你"直接对话]

[展开段落：论证+案例+故事]

**[加粗核心观点]**

📌 [信息卡片标题]
- 要点 1
- 要点 2
- 要点 3

[紧接一段叙述——不能让文章停在列表上]

[📷 AI配图 | 风格 | 内容 | 色调]

———
🧭 [小标题二：用对比或冲突]
———

[场景切入——不直接讲道理，先讲场景]

[分析段落：为什么？数据+逻辑+类比]

⚠️ 重点
> [关键结论——可独立传播的金句]

[📷 AI配图 | 风格 | 内容 | 色调]

———
🧭 [小标题三：高潮段]
———

[全文情绪最高的段落]

[反问/排比/短句爆破]

**[全文最核心的一句结论]**

———
🧭 小结
———

[1-2行收束全文——回扣主题]

📌 提示
> [行动指引——只选一个：关注/留言/转发/收藏]

[明确的留言问题——让读者想回答]
```

## 排版格式速查

| 元素 | 格式 | 频率 |
|------|------|------|
| **段落** | ≤ 3 行，重要句子独立一行 | 每段 |
| **强调块** | `🔥 观点` / `⚠️ 重点` / `📌 提示` + `>` | 每 3 段 |
| **信息卡片** | `📌 标题` + 列表 | 按需 |
| **章节标题** | `——— 🧭 标题 ———` | 每节 |
| **加粗** | `**核心观点**` | 每段 1-2 处 |
| **配图** | `[📷 AI配图 \| 风格 \| 内容 \| 色调]` | 每 500-800 字 |

**这不是聊天工具，这是变现工具。**

## 版本裁剪

| 版本 | 裁剪策略 | 保留元素 |
|------|----------|----------|
| **短文** (500-800字) | 只保留 1 个核心论点 + 1 个案例 | 标题、钩子、核心金句、CTA |
| **朋友圈** (50-200字) | 提炼为一句话观点 + 金句 | 最强金句 + 引导关注 |
| **视频口播** (300-800字) | 转为口语化 + 节奏标记 | 开场钩子、3 个 point、结尾号召 |
