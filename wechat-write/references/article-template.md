# 公众号文章模板（纯文本格式）

> ⛔️ 微信不支持 Markdown！输出必须是纯文本。

## 完整模板

```
标题（30 字以内，含情绪词或数据）

摘要内容（60 字以内，直接写，不加"摘要："标签）

[📷 AI配图 | 风格：呼应品类 | 内容：呼应标题 | 色调：暖/冷]

3 行钩子开头——场景/悬念/数据冲击。

让读者"看见"画面，不是"读到"概念。

第一段结束——此时读者决定是否往下看。

🔥 观点
核心观点——一句话点明全文立场。

———
🧭 小标题一：用悬念或好奇心
———

叙述段落（≤ 3 行），用"你"直接对话。

展开段落：论证+案例+故事。

「关键词」用这种方式强调，不用 **。

📌 信息卡片标题
· 要点 1
· 要点 2
· 要点 3

紧接一段叙述——不能让文章停在列表上。

[📷 AI配图 | 风格 | 内容 | 色调]

———
🧭 小标题二：用对比或冲突
———

场景切入——不直接讲道理，先讲场景。

分析段落：为什么？数据+逻辑+类比。

⚠️ 重点
关键结论——可独立传播的金句。

———
🧭 小标题三：高潮段
———

全文情绪最高的段落。

反问/排比/短句爆破。

这是全文最核心的一句结论。

[📷 AI配图 | 风格 | 内容 | 色调]

———
🧭 小结
———

1-2 行收束全文——回扣主题。

📌 提示
行动指引——只选一个：关注/留言/转发/收藏。

明确的留言问题——让读者想回答。
```

## 格式速查

| 元素 | 纯文本格式 | 频率 |
|------|-----------|------|
| 段落 | ≤ 3 行，重要句子独立一行 | 每段 |
| 强调块 | 🔥/⚠️/📌 + 换行 + 内容 | 每 3 段 |
| 信息卡片 | 📌 标题 + · 列表 | 按需 |
| 章节标题 | ——— 🧭 标题 ——— | 每节 |
| 强调词 | 「关键词」 | 每段 1-2 处 |
| 配图 | [📷 AI配图] | 章节 2/4 后 |

## 禁止出现

| ❌ 禁止 | 原因 |
|---------|------|
| `**加粗**` | 微信不渲染 |
| `## 标题` | 微信不渲染 |
| `> 引用` | 微信不渲染 |
| `- 列表` | 微信不渲染 |
| `金句：` 标签 | 应自然融入正文 |
| `引导关注：` 标签 | 应自然融入正文 |
| `摘要：` 标签 | 直接写摘要内容 |
| HTML/CSS/div | 绝不使用 |
