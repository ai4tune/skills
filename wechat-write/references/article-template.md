# 公众号文章模板（Markdown 格式）

## 模板

```markdown
# 标题（30 字以内，含情绪词或数据）

> 摘要内容（60 字以内）

![AI配图：呼应标题的封面 | 扁平插画 | 暖色](generate)

场景画面 / 悬念 / 数据冲击，3 行钩子开头。

让读者在 3 秒内决定往下看。

> 🔥 **核心观点**：一句话点明全文立场。

## 小标题一：用悬念或好奇心

叙述段落，用「你」直接对话。

展开论证：案例 + 数据 + 故事。

用 **加粗** 强调关键词。

- 要点 1
- 要点 2
- 要点 3

紧接叙述——不让文章停在列表上。

![AI配图：呼应当前内容 | 风格 | 色调](generate)

## 小标题二：用对比或冲突

场景切入——不直接讲道理，先讲场景。

分析段落：为什么？数据 + 逻辑 + 类比。

> ⚠️ **重点**：关键结论，可独立传播的金句。

## 小标题三：高潮段

全文情绪最高的段落。

反问 / 排比 / 短句爆破。

**这是全文最核心的一句结论。**

![AI配图：呼应内容 | 风格 | 色调](generate)

## 小结

1-2 行收束全文——回扣主题。

> 📌 **行动指引**：关注 / 留言 / 转发（只选一个）

留言问题——让读者想回答。
```

## 速查

| 元素 | Markdown 写法 | 频率 |
|------|-------------|------|
| 章节标题 | `## 标题` | 每节 |
| 加粗 | `**关键词**` | 每段 1-2 处 |
| 引用块 | `> 内容` | 每 2-3 段 |
| 列表 | `- 要点` | 按需 |
| 配图 | `![描述](generate)` | 第 2/4 节后 |
