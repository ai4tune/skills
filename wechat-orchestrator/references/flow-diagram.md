# 流水线流程图

## 全流程概览（7 阶段）

```
用户一句话
    │
    ▼
┌─────────────────────┐
│  ① 意图解析          │  编排技能自身处理
│  拆解结构化参数 +     │
│  匹配内容品类矩阵     │
└────────┬────────────┘
         │ ⚡ 快速确认（可自动跳过）
         ▼
┌─────────────────────┐
│  ② 选题生成          │  调用 wechat-topic
│  3-10 个选题方案      │
│  含品类标签 + 风险标注 │
└────────┬────────────┘
         │ 🛑 必停：用户选择选题
         ▼
┌─────────────────────┐
│  ③ 内容方案 Brief    │  调用 wechat-topic（Brief 功能）
│  标题方案 + 节奏规划  │
│  段落大纲（带钩子标记）│
│  阅读价值评估         │
└────────┬────────────┘
         │ 🛑 必停：用户确认大纲
         │ ⚠️ 未确认前禁止进入下一阶段
         ▼
┌─────────────────────┐
│  ④ 素材采集          │  调用 wechat-research
│  结构化素材卡片       │
│  可信度评级           │
└────────┬────────────┘
         │ ⚡ 默认继续（素材不足时暂停）
         ▼
┌─────────────────────┐
│  ⑤ 文案生成          │  调用 wechat-write
│  完整文章输出         │
│  五维度自检报告       │
└────────┬────────────┘
         │ 🔶 可选暂停：用户可修改
         │ ❌ 自检 < 35 分 → 自动重写 → 仍不过则暂停
         ▼
┌─────────────────────┐
│  ⑥ 推送 / 导出       │  调用 wechat-publish
│  默认：创建草稿       │
│  可选：导出 .md 文件  │
└────────┬────────────┘
         │ 🛑 必停：发布需确认
         ▼
┌─────────────────────┐
│  ⑦ 多版本（可选）     │  调用 wechat-write
│  朋友圈/短文/口播     │
└─────────────────────┘
         │
         ▼
    ✅ 完成
```

## 数据流

```
意图参数
  │
  ├──→ wechat-topic ──→ 选题卡片
  │                          │
  │                          ├──→ 内容方案 Brief + 锁定大纲
  │                          │          │
  │                          │          ├──→ wechat-research ──→ 素材卡片
  │                          │          │                            │
  │                          │          └──────── + ────────────────┘
  │                          │                    │
  │                          │                    ▼
  │                          └──────────→ wechat-write ──→ 文章 + 自检报告
  │                                                              │
  └──────────────────────────────────────────────────────→ wechat-publish
                                                                 │
                                                          草稿 / 导出文件
```

## 各阶段输入输出

| 阶段 | 输入 | 输出 | 调用技能 | 暂停 |
|------|------|------|---------|------|
| ① 意图解析 | 用户一句话 | 结构化参数 + 品类 | — | ⚡ |
| ② 选题生成 | 结构化参数 | 选题卡片 ×3-10 | wechat-topic | 🛑 |
| ③ 内容方案 | 选中的选题 | Brief + 锁定大纲 | wechat-topic | 🛑 |
| ④ 素材采集 | 选题 + 锁定大纲 | 素材卡片 ×5-8 | wechat-research | ⚡ |
| ⑤ 文案生成 | 大纲 + 素材卡片 | 文章 + 自检报告 | wechat-write | 🔶 |
| ⑥ 推送/导出 | 文章 + 封面 + 策略 | 草稿ID / .md文件 | wechat-publish | 🛑 |
| ⑦ 多版本 | 长文版本 | 短文/朋友圈/口播 | wechat-write | ⚡ |

## 暂停与恢复

- 每个暂停点记录当前阶段的完整状态
- 用户可在暂停点：
  - 选择/确认 → 继续下一阶段
  - 修改 → 重跑当前阶段
  - 回退 → 回到上一阶段
  - 终止 → 保留当前已有结果

## 自检联动流程

```
文章生成完成
    │
    ▼
自检得分 ≥ 40？─── 是 ──→ ✅ 展示文章，可选暂停
    │
    否
    ▼
自检得分 ≥ 35？─── 是 ──→ ⚠️ 展示修改建议，可选暂停
    │
    否
    ▼
自动重写低分段落 → 重新自检
    │
    ▼
仍 < 35？─── 是 ──→ 🛑 暂停：让用户决定（继续/修改/换题）
    │
    否
    ▼
✅ 继续流程
```

## 错误恢复

```
失败阶段 → 展示错误 → 提供选项：
  ├── 重试当前阶段
  ├── 跳过当前阶段（如素材采集失败，可用已有素材继续）
  └── 终止并保存已有结果（选题/大纲/素材均保留）
```
