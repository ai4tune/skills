# 公众号全流程编排技能

接收一句话指令，按顺序调用子技能完成公众号文章创作。

## ⛔️ 核心规则

> **你必须在暂停点停下来等用户回复，绝不能一口气生成全部内容。**

| 阶段 | 行为 | 暂停？ |
|------|------|--------|
| 1. 意图解析 | 解析指令 → 展示参数卡片 | ⚡ 快速确认 |
| 2. 选题生成 | 调用 wechat-topic → 展示 3-5 个选题 | ⛔️ **必须停下来等用户选** |
| 3. 大纲确认 | 展示文章骨架和内容方案 | ⛔️ **必须停下来等用户确认** |
| 4. 素材+写作 | 调用 wechat-research → wechat-write | 自动执行 |
| 5. 发布/导出 | 存草稿或导出 .md 文件 | ⛔️ **必须停下来等用户确认** |

## 阶段详解

### 阶段 1：意图解析

从用户一句话中提取：

```
📋 意图解析：
· 主题：[从指令提取]
· 品类：[匹配品类矩阵]
· 受众：[推断]
· 目标字数：1500-2500 字
· 流程终点：草稿

确认？或告诉我需要调整的部分。
```

### 阶段 2：选题生成 → ⛔️ 必须暂停

调用 `wechat-topic` 技能，展示 3-5 个选题卡片：

```
📝 为你生成了 3 个选题：

1. ⭐⭐⭐⭐⭐ 小龙虾经济学：为什么年轻人愿意花半天工资吃一顿？
2. ⭐⭐⭐⭐ OpenClaw 如何在红海市场杀出一条路？
3. ⭐⭐⭐⭐ 一只小龙虾的前世今生：从入侵物种到千亿产业

回复编号选择，或说「重新生成」。
```

⛔️ **此处必须停下来等用户回复编号。绝不自动选择。**

### 阶段 3：大纲确认 → ⛔️ 必须暂停

展示文章骨架：

```
📋 文章大纲：《小龙虾经济学》

开头：凌晨场景 + 悬念
章节 1：🧭 为什么排队 → 社交货币分析
章节 2：🧭 定价心理学 → 数据+案例
章节 3：🧭 供应链秘密 → 行业深度
结尾：金句收束 + 留言引导

预计 2000 字 | 品类：商业分析+生活方式

确认大纲？或告诉我要调整的部分。
```

⛔️ **此处必须停下来等用户确认。绝不跳过。**

### 阶段 4：素材采集 + 写作（自动）

1. 调用 `wechat-research` 采集素材
2. 调用 `wechat-write` 生成文章
3. 自动执行五维度自检

完成后展示摘要：

```
✅ 文案生成完成
📋 《小龙虾经济学》2136字 | 自检 42/50 ✅ | 配图 3 张

🔗 回复「看全文」查看完整文章
🔗 回复「进草稿」保存到草稿箱
🔗 回复「修改」提出修改意见
```

### 阶段 5：发布/导出 → ⛔️ 必须暂停

用户确认后默认保存为草稿，需用户说「发布」才直接发布。

## 自检联动

如果自检总分 < 35：
1. 展示扣分项和修改建议
2. 自动重写低分段落
3. 重新自检
4. 仍不达标 → 暂停等用户决定

## 偏好学习

每次用户选题后，自动更新 `wechat-topic/references/style-memory.md`：
- 记录推荐了什么 vs 用户选了什么
- 记录大纲修改了什么
- 下次选题时读取记忆，调整推荐权重

## 错误处理（静默降级）

| 场景 | 行为 |
|------|------|
| API 未配置 | 跳过该功能，继续下一步 |
| 配图生成失败 | 跳过配图，只输出文章 |
| 素材不可达 | 用已有素材继续 |
| 子技能超时 | 展示已完成部分 + 重试选项 |

绝不因中间失败丢失已完成的工作。

## 快捷标记

| 用户说 | 行为 |
|--------|------|
| "快速" / "直接" | 跳过意图确认 |
| "帮我选" | AI 选推荐指数最高的选题（但仍展示让用户确认） |
| "草稿" | 全流程自动，最终进草稿 |
| "导出" | 最终导出为 .md 文件 |

## 示例触发

- "帮我写一篇关于 AI 工具的公众号文章"
- "从选题到发布，帮我做一期关于 OpenClaw 的推文"
- "帮我快速出一篇端午节推文到草稿箱"
