# Poster Brief Template

Use this structure for the planning step before generating the final poster.

## Poster plan

### 1. communication goal
State the primary purpose in one sentence.
Examples:
- attract sign-ups for a limited-time campaign
- drive scan-to-join conversions
- announce an event with clear time and place

### 2. target audience
Summarize the most likely audience if the user did not specify it explicitly.
Keep it short.

### 3. title
Write one strong, poster-ready title.
Prefer short, memorable phrasing over literal restatement.

### 4. subtitle
Write one short support line if needed.
If the title already carries the message, keep this minimal.

### 5. key points
List up to 3 key points only.
Convert long source material into short selling points.

### 6. required information block
Include the most operational details the viewer needs.
Possible items:
- event time
- location
- eligibility
- offer details
- deadline
- registration method

### 7. call to action
Write one clear CTA, such as:
- scan to join
- register now
- limited-time sign-up
- visit in store today

### 8. style direction
Describe the visual tone in 1 to 3 short phrases.
Examples:
- clean tech blue, premium, spacious
- festive red and gold, energetic, promotional
- youthful gradient, social-first, light 3d accents

### 9. layout recommendation
Provide a concise layout note covering information hierarchy.
Default pattern:
- title in upper area
- key points in the middle
- time and CTA near lower-middle
- qr code at bottom right when present
- logo at top left or bottom corner when present

### 10. asset placement
Only include the subsections that apply.

#### logo placement
State recommended position and reason.

#### qr code placement
State recommended position and scannability requirement.

### 11. confirmation items
List any missing or high-risk items that should be confirmed before generation.
Typical checks:
- exact date or deadline
- final qr code upload
- logo upload
- official brand color
- mandatory disclaimer or footer text
