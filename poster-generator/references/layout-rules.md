# Layout Rules

## Core hierarchy

Prioritize information in this order unless the user clearly requests otherwise:
1. title
2. event time or deadline
3. core offer or key points
4. call to action
5. qr code
6. logo

Do not let supporting text compete with the title.
Avoid more than one visual focal point.

## QR code rules

- Default placement: bottom right.
- Keep visible padding around the qr code.
- Keep the qr code front-facing and not distorted.
- Do not place text, patterns, or decorative elements over the qr code.
- Do not shrink it so much that scanning becomes doubtful.
- If the campaign depends heavily on scan conversion, make the qr code slightly larger and pair it with a direct CTA.

## Logo rules

- Default placement: top left or bottom corner.
- Preserve aspect ratio.
- Do not crop, stretch, stylize, or blend it into the background.
- Keep the logo visually subordinate to the campaign message.
- If background contrast is weak, place the logo on a subtle clean patch or reserved space.

## Time and date rules

- Show the activity time clearly.
- Use concise formatting.
- On promotional posters, the deadline should be immediately noticeable.
- If time is missing and the poster would be misleading without it, ask before final generation.

## Copy compression rules

- Convert long text into punchy poster language.
- Limit key points to 3.
- Prefer short numeric offers, time limits, and action verbs.
- Avoid paragraphs.

## Composition defaults

Use these defaults unless the user requests another structure:
- upper area: title and subtitle
- middle: visual hero or key points
- lower middle: time and CTA
- lower right: qr code when present
- corner: logo when present

## Failure prevention

If any of the following are true, do not rush into final generation:
- the title is still vague
- the offer is unclear
- the date is missing for a time-sensitive event
- the user mentioned a qr code but has not uploaded it yet
- the user mentioned a logo but brand presentation matters and there is no logo file yet
