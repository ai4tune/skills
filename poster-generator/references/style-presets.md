# Style Presets

Use these presets when the user gives a vague style request or no style request.

## 1. tech-clean
Best for product launches, digital services, enterprise activities, and modern event promotion.

Visual cues:
- blue or cyan-led palette
- clean gradients
- spacious composition
- crisp typography
- subtle depth, glow, or abstract geometry

## 2. premium-minimal
Best for higher-end services, brand events, executive communication, or polished recruitment materials.

Visual cues:
- restrained palette
- strong whitespace
- elegant typography
- simple geometric accents
- controlled, editorial composition

## 3. festive-promo
Best for holiday campaigns, limited-time discounts, store promotions, and conversion-heavy marketing.

Visual cues:
- warm, vivid palette
- energetic layout
- stronger contrast
- promotional badges or highlight blocks
- obvious urgency cues

## 4. youthful-social
Best for campus events, community activities, youth programs, and social-media-forward promotions.

Visual cues:
- playful gradients
- lively composition
- brighter accents
- dynamic shapes
- approachable, upbeat tone

## 5. official-steady
Best for formal notices, state-owned enterprise communication, internal campaigns, and information-first events.

Visual cues:
- stable composition
- restrained color usage
- clear information blocks
- less decorative noise
- authoritative and readable presentation

## Preset selection rules

- If the user says technology, digital, ai, smart, or futuristic, default to tech-clean.
- If the user says simple, high-end, premium, or minimalist, default to premium-minimal.
- If the user says promotion, discount, limited time, festival, or福利, default to festive-promo.
- If the audience is students, creators, or a local community group, consider youthful-social.
- If the communication is formal or organizational, consider official-steady.
