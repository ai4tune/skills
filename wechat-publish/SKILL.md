# 公众号推送后台技能

将写好的文章推送到微信公众号后台，或导出为标准化本地文件。内置多层安全护栏，防止误发布。

Read [references/publish-checklist.md](references/publish-checklist.md) 获取发布前检查清单。
Read [references/export-template.md](references/export-template.md) 获取标准化导出格式。
Read [references/api-setup-guide.md](references/api-setup-guide.md) 获取微信 API 配置和部署指南。

## 安全护栏

> ⚠️ **本技能默认行为是创建草稿，绝不自动发布。**
>
> 直接发布需要同时满足以下条件：
> 1. 用户显式传入 `publish_mode: publish`
> 2. 用户提供二次确认口令 `confirm: "I_CONFIRM_PUBLISH"`
> 3. 文章通过发布前检查清单的所有必检项
>
> 任何一项不满足，技能将拒绝发布并说明原因。

## 输入规范

| 参数 | 必填 | 说明 |
|------|------|------|
| 文章内容 | ✅ | Markdown 或富文本格式的文章（来自 wechat-write） |
| 标题 | ✅ | 文章标题 |
| 摘要 | ✅ | 文章摘要（≤120 字） |
| 封面图 | ❌ | 封面图片路径或 URL（不提供则使用默认封面） |
| 目标账号 | ❌ | 公众号账号标识（如有多个账号） |
| publish_mode | ❌ | 发布模式（默认 `draft`） |
| scheduled_time | ❌ | 定时发布时间（仅 `schedule` 模式需要） |
| confirm | ❌ | 发布确认口令（仅 `publish` 模式需要） |

## 发布模式

| 模式 | 参数值 | 行为 | 是否需要确认 |
|------|--------|------|-------------|
| **草稿** | `draft` | 创建草稿到公众号后台 | ❌ 不需要 |
| **预览** | `preview` | 发送预览到指定微信号 | ❌ 不需要 |
| **定时发布** | `schedule` | 设置定时发布（需提供时间） | ⚠️ 需确认时间 |
| **直接发布** | `publish` | 立即群发 | ✅ 需口令确认 |
| **本地导出** | `export` | 导出标准化 `.md` 文件 | ❌ 不需要 |

## 工作流程

1. **内容接收与格式化**
   - 接收文章 Markdown 内容
   - 转换为公众号兼容的富文本格式
   - 处理图片上传（如有本地图片引用）
   - 应用排版样式

2. **封面图生成**（如未提供封面图）
   自动生成符合公众号规范的封面图：
   - **尺寸规范**：21:9 宽高比（推荐 900×383 像素），这是公众号在手机端信息流中显示效果最佳的比例
   - **生成方式**（按优先级）：
     1. 用户提供的封面图 → 自动裁剪为 21:9
     2. AI 生图 API → 根据文章标题和关键词自动生成
     3. 用户从对话中上传图片 → 作为封面使用
   - **风格参数**：可指定风格（科技感/温暖/极简/商务），默认根据文章品类自动匹配
   - **正文配图**：根据文章中的 `[📷 配图建议]` 标记，批量生成正文插图

3. **发布前检查**（参照 [references/publish-checklist.md](references/publish-checklist.md)）
   - 必检项：标题长度、摘要完整性、正文非空、敏感词扫描
   - 推荐项：封面图尺寸、原创声明、来源标注
   - 所有不通过项生成检查报告

4. **执行操作**
   - 根据 `publish_mode` 执行对应操作
   - 记录操作结果（成功/失败 + 详情）

5. **返回结果**
   - 返回结构化执行结果

## 标准化导出（export 模式）

当 `publish_mode: export` 时，输出一个包含完整元信息的标准化 `.md` 文件，格式参照 [references/export-template.md](references/export-template.md)。

导出文件包含：
- **元信息头部**：标题、作者、创建日期、字数、品类标签、目标受众、关键词
- **正文内容**：完整的 Markdown 文章
- **附录**：
  - 金句摘录（可制作金句图）
  - 参考来源列表
  - 配图建议
  - 自检得分摘要
  - 多版本索引（如有）

导出文件命名规则：`[日期]_[标题简写].md`，例如 `20240615_小龙虾经济学.md`

## 输出规范（发布模式）

```markdown
## 发布结果

**操作**：[创建草稿 / 发送预览 / 设置定时 / 直接发布 / 本地导出]
**状态**：[✅ 成功 / ❌ 失败 / ⚠️ 部分成功]

**详情**：
- 草稿 ID：[ID]（仅草稿模式）
- 预览链接：[URL]（如可获取）
- 定时时间：[时间]（仅定时模式）
- 群发消息 ID：[ID]（仅直接发布模式）
- 导出文件：[文件路径]（仅导出模式）

**检查报告**：
- ✅ 标题长度合规（[N] 字）
- ✅ 摘要已填写
- ✅ 正文字数：[N] 字
- [⚠️/❌] 敏感词检测：[结果]
- [⚠️/❌] 封面图：[状态]

**后续操作建议**：
- [登录公众号后台查看草稿]
- [在手机端预览效果]
- [确认无误后手动发布 / 设置定时发布]
```

## 输出规则

- 永远返回检查报告，即使所有项目通过
- 草稿模式必须返回草稿 ID 或后台入口提示
- 导出模式必须返回完整的 `.md` 文件内容
- 失败时返回具体错误信息和建议解决方案
- 不在输出中包含账号密码、access_token 等敏感信息

## API 集成说明

本技能设计兼容以下方式操作公众号：

1. **微信公众平台 API**（需 access_token）
   - 创建草稿：`POST /cgi-bin/draft/add`
   - 预览：`POST /cgi-bin/message/mass/preview`
   - 群发：`POST /cgi-bin/message/mass/sendall`

2. **第三方工具**（如 WeRoBot、WeChatPy）
   - 通过封装库调用

3. **手动模式**（无 API 接入时）
   - 输出格式化好的 HTML
   - 提供复制粘贴到公众号编辑器的指引
   - 生成封面图建议

> 当前默认工作在**手动模式**。如需接入 API，需额外配置 AppID 和 Secret。
